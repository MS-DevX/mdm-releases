# MDM Download Manager — Public Releases & Installers

Official release binaries and one-line installers for [MDM Download Manager](https://marthdownloadmanager.msdevx.com).

## 🚀 Quick Install

### Linux & macOS (Terminal)
```bash
curl -fsSL https://raw.githubusercontent.com/MS-DevX/mdm-releases/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
powershell -ep Bypass -c "irm https://raw.githubusercontent.com/MS-DevX/mdm-releases/main/install.ps1 | iex"
```

## 📦 Downloads & Releases

All desktop installers (`.AppImage`, `.exe`, `.dmg`), CLI binaries, and cryptographic checksums are available on the [GitHub Releases Page](https://github.com/MS-DevX/mdm-releases/releases).
